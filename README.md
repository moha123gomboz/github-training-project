# التدريب العملي على Git و GitHub - موقعي الشخصي

## وصف المشروع
هذا المشروع عبارة عن موقع ويب شخصي بسيط عملته عشان أطبق فيه مهاراتي في تصميم واجهات الويب، وكجزء أساسي من التدريب العملي على استخدام أوامر (Git) ورفع الأكواد وإدارة المشاريع على منصة (GitHub). المشروع بيعرض معلومات عني، مهاراتي البرمجية، وطرق التواصل معي.

## التقنيات اللي استخدمتها
* **HTML5 & CSS3:** لبناء وتنسيق هيكل الصفحات.
* **JavaScript:** لإضافة بعض التفاعلات البسيطة.
* **Bootstrap 5:** عشان الموقع يكون متجاوب (Responsive) وشكله مرتب على الموبايل واللابتوب.
* **Git & GitHub:** لإدارة المشروع، عمل Commits، ورفع الشغل أونلاين.

## صفحات المشروع
الموقع بيتكون من 3 صفحات رئيسية مربوطين بـ Navbar:
1. **الصفحة الرئيسية (`index.html`):** واجهة ترحيبية بسيطة.
2. **من أنا (`about.html`):** نبذة عني وعن المهارات اللي بتعلمها.
3. **تواصل معي (`contact.html`):** روابط حساباتي المهنية (GitHub, LinkedIn, إلخ).
